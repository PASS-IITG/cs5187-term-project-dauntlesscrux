# Evaluation Artifacts

- `typestate_checker_eval_v2.py`: the Version 2 hand-written snippet benchmark.
- `eval_v2_stdout.log`: output log preserved from the recorded run.
- `benchmark_protocol.md`: the test composition, interpretation, known coverage gap, and recommended next steps.
- `evaluation_checklist.md`: next actions before final claims.

The script was intentionally preserved so results are reproducible, but its source-pattern simplifications (including the known PEM reset gap) must be accounted for. Do not present its 100% scores as general accuracy.
